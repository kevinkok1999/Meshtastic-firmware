# Dormant pinned real pool observation

The opt-in DEV build patches exact immutable StaticPoolPacketManager sources and compiles the observer adapter, with no observer installed by default. Actual pool events are observational only and never change allocation, enqueue, dequeue, priority, scheduling, free, or radio outcomes. An observer may be installed once at fully idle startup and must outlive the pool. The adapter tracks exact generation-tagged lifecycle, including RX, detach and requeue; invalid duplicate queue/free faults are latched, not treated as a new message. Host tests deliberately exercise the real queue full branch via invalid duplicate enqueue (impossible with correct unique ownership and equal pool/queue capacity), exact actual pool reuse, and unmodified default behavior. No RF governor instantiation, sender, MyMesh override or radio activation exists. Install only in an isolated hardware-validated later path after verifying observer fault handling and all physical/legal gates.
