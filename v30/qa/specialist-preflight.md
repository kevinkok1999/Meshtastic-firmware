## Security / journal

Choose and document wire layout with exact maximum message sizes; no incompatible guess.
- Public parse/signature verification for relays; only intended recipient decrypts authenticated content and triggers inbox. Unknown senders receive bounded quota, cannot elevate trusted priority.
- ACK is a distinct signed/encrypted recipient-bound message/domain, own logical ID, reference to original logical ID/digest, original sender+recipient pair, expected signer full key. ACK-of-ACK invalid. Only durable acceptance produces ACK. Valid duplicate re-ACK from durable marker, no duplicate UI; ACK can precede TX callback, later callback may not regress state.
- Commit inbox and replay marker atomically before ACK/display; storage full neither accepts nor marks seen. Single persistent replay owner; explicit bounded replay horizon/late-frame policy, no silent eviction of unexpired tombstones. Trusted/untrusted clock distinct; no fake freshness or exact time-without-clock. Reject TTL=0, mutable age cannot extend signed expiry. Reserve nonces transactionally by direction/peer before use, safe after reboot; failure means no send.
- Portal privileged POST requires physical intent or explicitly approved short-lived session, strict approved Host and non-null approved Origin, token not in URL, bounded parsing; timeout, failure, manual stop, and concurrent battery deterioration preserve stricter power mode.

## Map budget and resilience

Ruling: immutable full factory pack; normal app OTA preserves tiles; small compiled rescue outline/place map (~100–200KiB only if app headroom remains >=256KiB). Explicit signed map update via USB; verify entire artifact before destructive area write, durable pending/recovery marker in small metadata, exact partition 0x7D0000..0xC8FFFF, readback signature/hash, no implicit format. On interruption rescue mode + resumable external installer; do not promise full previous pack survives erase. Preserve identity/user data and both app slots. Test old V29 rollback compatibility, no cache deletions in immutable map namespace. Validate actual LittleFS geometry/full image/freespace, not only payload bytes.
