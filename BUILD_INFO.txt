Connection:
  Off-grid = LoRa + ESP-NOW + optional XBee + encrypted recovery/store-carry-forward
  Internet = Wi-Fi + encrypted MQTT; no silent radio fallback
  Smart = explicit opt-in coexistence of permitted Internet + off-grid paths

Privacy:
  Private/Maximum direct text chats require destination-specific Meshtastic PKI encryption
  MQTT payload encryption forced on
  MQTT TLS server authentication uses the built-in CA bundle
  MQTT map/location reporting forced off
  MQTT gateway/client ID rotates per reboot
  Maximum profile disables Bluetooth broadcast surface

Privacy tunnel:
  Fail-closed tunnel policy framework included.
  No unproven full WireGuard provider is advertised or enabled in this V6 candidate.
